How we use AI

AI helps riders decide where to go. Today it does three jobs inside Trilyt.

  1. It recommends places

    It surfaces the destinations, stops and experiences most worth a rider's time, ranked for the trip being planned rather than by generic popularity.

  2. It learns what you like

    Trilyt learns from how each rider plans, saves and rides, and uses that to personalise what it suggests next.

  3. It grows the places database

    When a rider looks for a spot we don't cover yet, AI gathers information about it from across the web and returns it in a clean, structured format. That helps us add verified places to Explore, so coverage grows with our community.
